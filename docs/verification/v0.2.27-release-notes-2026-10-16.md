# v0.2.27 release notes — 2026-10-16

**The language-lock fix that actually holds.** v0.2.26 shipped the first
attempt (a system instruction at the front of every chat request); the live
A/B test on a real machine showed the model ignored it — a Chinese reply in
the conversation still locked every later reply Chinese. v0.2.27 carries the
measured form: for confidently-English messages, one short
"(Respond in the language of this message: English.)" line is appended to
your message on the request only — never in your transcript — and it holds
even after several Chinese turns. Chinese questions are untouched (the
model naturally answers in the language you write); so are verification,
pairing, and everything else from 0.2.25/0.2.26.

## For testers

Installers remain unsigned by owner decision. Self-update: 0.2.26 clients
pick this up automatically on the start/six-hour check.

Before you host: privacy first-run warning

When this installation serves the swarm, peers that serve your requests can read the prompts they serve. Hosting is your choice and can be turned off at any time.

  • No telemetry by default; diagnostics export is opt-in and excludes prompt/completion content.
  • Cooperative modes deliver the prompt to the whole micro-swarm roster (mode + peer count shown before each request).
  • Cross-check (on by default): after each reply, a different model in the swarm re-reads the question and the answer and returns a verdict shown on the reply label — the answer itself is never rewritten (config: allow_cross_check).

Privacy

  • Prompts/completions are structurally redacted from all node logs.
  • The tracker is content-blind: it never sees prompts or completions.
  • Secrets (identity seed, engine key, lease tokens) stay in the node process — never in this UI.
  • Serving peers read the prompts they serve; family-verified chat (always on — the disclosure below states the cost every turn) additionally sends the conversation — in a form the verifying peers can read — to every verification peer. Transport is encrypted; there is no confidential-computing claim.

full document: docs/privacy.md (shipped with the app).

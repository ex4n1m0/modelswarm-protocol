Picker census stub harness

Loads the REAL ../ui/index.html into a same-origin iframe with a stubbed window.__TAURI__ bridge, then asserts the per-model live peer chips, the card order, and the downloaded/selected visibility for two scenarios: census reachable and census unreachable. The list_models stub returns cards exactly as the daemon does — pre-joined (census_chip) and in the canonical order — so this harness pins the RENDER contract; the join/order/chip logic itself is pinned by the Rust unit tests in src/app.rs.

Run: serve the crate root over http — e.g. python -m http.server 4817 from crates/modelswarm-desktop — then open http://127.0.0.1:4817/ui-harness/census.html. Opening from file:// cannot work (the harness fetches the UI same-origin).

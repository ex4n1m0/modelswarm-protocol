Before you host: privacy first-run warning

When this installation serves the swarm, peers that serve your requests can read the prompts they serve. Hosting is your choice and can be turned off at any time.

  • No telemetry is sent by default; diagnostics export is opt-in and structurally excludes prompt and completion content.
  • Cooperative execution modes deliver the prompt to the whole micro-swarm roster: the mode and the peer count are shown before every such request (see the roster disclosure on the request card below).

Privacy

  • Prompts/completions are redacted from all node logs by a structural redactor (never a convention).
  • The control plane is content-blind; it never sees prompts or completions.
  • Diagnostics export is opt-in and excludes prompt/completion content by schema.
  • Secrets (identity seed, tokens, lease secrets) stay in the node process — they never enter this webview.

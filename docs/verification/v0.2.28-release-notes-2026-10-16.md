# v0.2.28 release notes — 2026-10-16

**No more manual relay setup.** A fresh install now learns the community
relay address automatically from the tracker (ADR-039) — install, pick a
model, host: cross-network fallback just works. If you ever placed the
`relay.addr` file by hand, it keeps winning (the operator override).
Diagnostics → Hosting detail now shows the effective relay and where it
came from. Relayed turns remain what they always were: fallback-only,
content-blind, admission-ticketed, slower by design.

Also in this release: cleanly-served swarm requests now leave a
counts-only trace on the serving machine's log (previously only errors
logged — the diagnostics gap found during the machine-C session).

## For testers

Installers remain unsigned by owner decision. Self-update: 0.2.27 clients
pick this up automatically on the start/six-hour check.

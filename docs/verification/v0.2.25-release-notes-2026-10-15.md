# v0.2.25 release notes — 2026-10-15

**The relay release.** Direct stays the default; when a direct connection
cannot be made, chat now falls back honestly through the first public
ModelSwarm relay instead of failing. And the app gets simpler: everything
on by design, fewer switches, no cloud anywhere.

## What's new

- **Relay fallback (F2B adoption).** Chat always dials direct-first. When
  the direct connection fails, the request rides a circuit through the
  relay and the app says so — a direct failure is never hidden, and
  relayed turns are expected to be slower than direct ones. Serving peers
  reserve their slots on the relay up front, and the roster/peer picker
  now classify relay-reachable peers as reachable. Reservation caps,
  no-reservation refusal, and deadline/byte cuts are enforcement-tested
  (they bite, they don't just print).
- **The first public relay is live**, hosted on the owner's Oracle
  free-tier VM (the F2B deployment record is `docs/verification/`'s
  relay deployment note). The relay binary binds loopback by default;
  going public is an explicit `--public` opt-in (ADR-018 discipline).
- **Relay admission tickets (ADR-038, the D12 close).** The tracker
  mints a short-lived admission ticket with every heartbeat; clients
  hold a heartbeat-fresh supply and present one before the relay accepts
  a circuit; the relay enforces the tracker's caps (per-IP buckets
  included), and absent operator flags stay exactly uncapped as
  documented. Reviewed end to end: adversary matrix S1–S9 adjudicated,
  T/R §6.2 verdict APPROVE, byte-parity between the TS and Rust ticket
  spellings proven against frozen golden vectors in CI.
- **Everything on by design (owner directives 2026-10-15).**
  Family-verified chat is ALWAYS ON — the requester election toggle is
  retired; your conversations are verified across the swarm every turn,
  slower by design, with the hub never seeing any of it (the serving
  disclosure and its acknowledgment survive). The main page is now the
  operating surface only; everything else lives behind File / Settings /
  Help.
- **No cloud, anywhere.** The DeepSeek key is removed completely — the
  key era is over. The assistant panel runs on this machine's OWN hosted
  model through the local gateway while you host, and falls back to the
  built-in static help floor otherwise. Nothing typed into the assistant
  leaves this machine anymore. (The deferred key-rotation item is closed
  by removal.)
- **Under the hood:** a test-only env-lock fix that unflaked the
  Windows-runner CI race caught on the 0.2.24 train; golden-vector
  re-pointing so the ticket tests run against frozen protocol fixtures.

## For testers

Installers remain unsigned by owner decision — SmartScreen will warn on
first run ("more info → run anyway"); this is reputation, not detection.
Self-update: leave the app running — it checks on start and every six
hours, verifies against the built-in key, and restarts to install.
0.2.24 clients pick this release up automatically.

# v0.2.26 release notes — 2026-10-15

**The language-lock fix.** Small release, one behavior change: the swarm
chat can no longer get stuck answering in the wrong language.

## What's new

- **The chat language pin.** If one reply ever came out in the wrong
  language (for this bilingual model, usually Chinese), every reply after
  it stayed in that language — no matter what you asked, and the
  temperature control could not break it (both reproduced against the
  shipped model and engine before this fix). Every chat request now
  carries one neutral instruction — "Reply in the same language as the
  user's latest message" — as a system turn on the request only. It rides
  both the swarm path (peers render it) and the local engine, it never
  enters your visible transcript, it constrains language and nothing
  else, and the verification/pairing determinism contracts are untouched.
- Everything else is v0.2.25 exactly (the relay release).

## For testers

Installers remain unsigned by owner decision — SmartScreen will warn on
first run ("more info → run anyway"); this is reputation, not detection.
Self-update: leave the app running — 0.2.25 clients pick this up
automatically on the start/six-hour check.
